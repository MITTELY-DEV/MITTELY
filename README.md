# MITTELY — Independent Design Marketplace

Premium UI kits, dashboards, templates, and components with fair 70/30 pay
for designers. Built with vanilla HTML/CSS/JS on the front end and Supabase +
Paystack on the back end. Zero build tools.

## Tech Stack

- **Front end**: HTML5, CSS3, vanilla JavaScript (ES6+). No frameworks,
  no build tools, no npm.
- **Icons**: Font Awesome 6 Free via cdnjs only. No emojis in the UI.
- **Back end**: Supabase — PostgreSQL, Auth (Google only), Storage,
  Edge Functions (Deno).
- **Payments**: Paystack Inline + server-side verification in an Edge Function.
