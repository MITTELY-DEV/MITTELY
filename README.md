# MITTELY — Independent Design Marketplace

Premium UI kits, dashboards, landing pages, and components from independent designers. Built with vanilla HTML/CSS/JS, Supabase, and Paystack.

---

## Tech Stack

- **Frontend:** HTML5, CSS3, vanilla JavaScript (ES6+). No frameworks, no build tools.
- **Icons:** Font Awesome 6 Free via CDN. Zero emojis.
- **Backend:** Supabase (PostgreSQL, Auth with Google OAuth, Storage, Edge Functions on Deno).
- **Payments:** Paystack (client-side public key, server-side verification in an Edge Function).
- **Currencies:** USD (base, all prices stored) and GHS (display + charge, live conversion).
